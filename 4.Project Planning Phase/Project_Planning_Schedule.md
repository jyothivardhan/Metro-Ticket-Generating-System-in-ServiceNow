# Phase 4: Project Planning Phase - Schedule & Work Breakdown

## Project: Metro Ticket Generating System – ServiceNow

### 1. Work Breakdown Structure (WBS)

```
1.0 Project Initialization & Ideation
    1.1 Problem Statement Definition
    1.2 Commuter Empathy Mapping
    1.3 Brainstorming & Idea Prioritization

2.0 Requirement Analysis
    2.1 Customer Journey Mapping
    2.2 Functional & Non-Functional Specifications
    2.3 Data Flow Diagrams & User Stories
    2.4 Technology Stack Selection

3.0 Project Architecture & Design
    3.1 Problem-Solution Fit Analysis
    3.2 Data Schema Design (u_metro_ticket)
    3.3 Service Portal Wireframing
    3.4 Solution Architecture Definition

4.0 Development & ServiceNow Configuration
    4.1 Scoped Application & Table Creation
    4.2 Record Producer Configuration & Variable Mapping
    4.3 Client Scripts for Dynamic Fare Calculation
    4.4 UI Policies & Data Validation Rules
    4.5 Custom Commercial Services Widget Development (HTML/CSS)
    4.6 Portal Page Assembly in Service Portal Designer

5.0 Testing & Quality Assurance
    5.1 Functional Testing of Ticket Booking
    5.2 Boundary & Negative Testing (Identical stations, max passengers)
    5.3 User Acceptance Testing (UAT)
    5.4 Performance & Latency Verification

6.0 Documentation, Demonstration & Source Control
    6.1 Final Project Report Preparation
    6.2 GitHub Repository Setup & Sync
    6.3 Video Demonstration Recording
    6.4 Final Submission Packaging
```

# Phase 2: Requirement Analysis - Technology Stack

## Project: Metro Ticket Generating System – ServiceNow

### 1. Platform & Infrastructure
- **Enterprise Platform:** ServiceNow (Vancouver / Washington DC / Xanadu Releases)
- **Deployment Model:** ServiceNow Personal Developer Instance (PDI) / Cloud Hosted
- **Architecture:** Scoped Application Architecture (`x_..._metro_ticket` or `u_metro_ticket`)

---

### 2. Frontend & Portal Technologies
- **Service Portal Framework:** ServiceNow Service Portal (AngularJS 1.5, Bootstrap 3 Grid)
- **Styling & Presentation:** HTML5, CSS3, SCSS
- **Custom Widget Engine:** Service Portal Widget Editor (HTML Template, Client Controller, Server Script, CSS/SCSS)
- **Icons & Visuals:** FontAwesome & Glyphicons

---

### 3. Backend & Business Logic
- **Database & Data Modeling:** ServiceNow Tables & Columns, Dictionaries, Choice Lists
- **Catalog & Request Engine:** ServiceNow Record Producer & Service Catalog
- **Client Scripting:** JavaScript (ES5/ES6) - `onLoad`, `onChange`, `onSubmit`
- **Policy Automation:** ServiceNow UI Policies & UI Actions
- **Server Scripting:** ServiceNow GlideSystem (`gs`), GlideRecord (`gr`), Business Rules
- **State Management:** Choice-driven ticket state transitions

---

### 4. Development & Source Control Tools
- **IDE / Configuration:** ServiceNow Studio & Flow Designer
- **Version Control:** Git & GitHub (`https://github.com/jyothivardhan/Metro-Ticket-Generating-System-in-ServiceNow`)
- **Documentation & Diagrams:** Markdown, Mermaid, Microsoft Word/PDF
